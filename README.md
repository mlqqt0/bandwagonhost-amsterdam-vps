## 退款政策：30 天是真的，但有几个坑

搬瓦工提供 30 天退款保证，但这个 30 天是从**账户注册日**起算的，从 VPS 购买日起算。如果你的账号已经注册超过 30 天才下单这台机器，退款会被直接拒绝，这是最高频的踩坑点。

退款条件里还有几条值得提前知道：

- **退款是账号级别的。** 退款批准后，账号下所有 VPS、快照、备份数据会立即永久删除，不可恢复。申请前先把数据拷到本地，快照救不了。
- **每个账号只有一次退款机会**，用过之后这个账号（包括名下其他账户）就不再享有退款权利。账号本身不会被注销，还能继续购买。
- **其他条件**：账户状态正常无争议记录、IP 未进黑名单且没用过免费换 IP、当月流量消耗低于配额的 10%、账号下服务总数（含已取消）不超过 3 台。对累计付款金额和次数也有上限要求，单买这台 39 美元年付不会触及。
- **退款原路返回**，支付宝和 PayPal 很快到账，信用卡要 3–14 天。

限量套餐是抢购性质，建议开通后尽快测试线路是否符合预期，重点看晚高峰（20:00–23:00）的延迟和丢包，测试期控制流量别超过 10%。另外 KiwiVM 面板支持免费切换机房（限支持迁移的套餐），线路不满意可以先换机房再考虑要不要退款。

这几条大多只写在条款或后台说明里，但对使用影响不小。

1. **EUNL_1 迁出后回不去。** 机房必须在新购时选定；如果之后在 KiwiVM 面板把机器迁出 EUNL_1，就无法再迁回来。别为了换个 IP 顺手点迁移。
2. **限量套餐常年缺货。** 补货间隔没有规律，从几周到几个月不等，补货后常在几小时内售罄。可以在缺货套餐页面点 "Notify Me" 订阅邮件通知；另外搬瓦工历史上曾多次在春节、618、黑五这类时间点前后补货或推出新限量版。

4. **换 IP 要收费。** 7.39 美元一次，而且必须是已被封锁的 IP 才能申请更换。结合第三方实测提到的“IP 质量一般”，这笔潜在开销要计入心理价位。
